🏆 Infestation Tournament Manager:
Sistema completo para gestão de campeonatos da comunidade do jogo Infestation: The New Z.

A complete tournament management system for the Infestation: The New Z game community.

-------------------------------------------------------------------------------------------------------------------------------------------------------------

PT-BR: O Infestation Tournament Manager foi desenvolvido para resolver um problema real da comunidade: a falta de uma plataforma centralizada para organizar, gerenciar e acompanhar campeonatos. Antes, tudo era feito via Discord, sem organização adequada.

🎯 Funcionalidades Principais:
Gestão de Campeonatos	Criação, edição, ativação/desativação e deleção de campeonatos (apenas admin)
Sistema de Times	Criação de times, adição/remoção de jogadores, transferência de liderança
Inscrições	Times se inscrevem em campeonatos, com aprovação/reprovação por admin
Autenticação JWT	Login/registro de usuários com roles (User/Admin)
Controle de Status	Campeonatos com status: "Não Iniciado", "Em Andamento", "Finalizado"
Definição de Campeões	Admin define o time campeão ao final do campeonato

👥 Perfis de Usuário
Perfil e Permissões
Jogador (User)	Criar time, gerenciar jogadores (se líder), inscrever time em campeonatos, ver seus times e inscrições
Administrador (Admin)	Tudo que o jogador faz + criar/editar/deletar campeonatos, aprovar/reprovar inscrições, eliminar times, definir campeões


--------------------------------------------------------------------------------------------------------------------------------------------------------------

EN: Infestation Tournament Manager was developed to solve a real community problem: the lack of a centralized platform to organize, manage, and track tournaments. Previously, everything was done via Discord without proper organization.

🎯 Key Features:
Tournament Management	Create, edit, activate/deactivate, and delete tournaments (admin only)
Team System	Create teams, add/remove players, transfer leadership
Registrations	Teams register for tournaments with admin approval/rejection
JWT Authentication	User login/registration with roles (User/Admin)
Status Control	Tournaments with status: "Not Started", "In Progress", "Finished"
Champion Definition	Admin defines the champion team at tournament end

👥 User Roles:
Role and Permissions
Player (User)	Create team, manage players (if leader), register team in tournaments, view their teams and registrations
Administrator (Admin)	All player permissions + create/edit/delete tournaments, approve/reject registrations, eliminate teams, define champions
